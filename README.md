##  Purpose

This repository is designed to help developers review essential concepts for technical interviews across web development and backend domains. It is organized to make it easy to study one topic at a time and to find the most important interview points quickly.

##  How to Use

1. Open this folder in your editor or file explorer.
2. Navigate to the topic you want to review.
3. Open the markdown note for that topic.
4. Study the key concepts, commands, architecture patterns, and interview-ready explanations.

##  Recommended Study Flow

- Start with the fundamentals: [HTML](Notes/01-HTML/), [CSS](Notes/02-Css/), and [JavaScript](Notes/03-JavaScript/).
- Move into frameworks and libraries: [React.js](Notes/04-React.js/) and [Next.js](Notes/05-Next.js/).
- Review strong typing and backend fundamentals: [TypeScript](Notes/06-TypeScript/) and [Nest.js](Notes/07-Nest.js/).
- Study backend and systems topics: [Python](Notes/08-Python/), [Django](Notes/09-Django/), [Flask](Notes/10-Flask/), [FastAPI](Notes/11-FastAPI/), [PostgreSQL](Notes/12-PostgreSQL/), [Docker](Notes/17-Docker/), [Kubernetes](Notes/18-Kubernetes/), and [System Design](Notes/19-System-Design/).
- Finish with tool and algorithm review: [Git](Notes/13-Git/), [Linux](Notes/14-Linux/), [Algorithms](Notes/15-Algorithms/), and [Data Structures](Notes/16-DataStructure/).
